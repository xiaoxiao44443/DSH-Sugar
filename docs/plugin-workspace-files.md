# 插件的工作区文件视图

Sugar 为安装的 Host 插件提供 Node 文件兼容层。插件工具由工作区会话调用时，`/workspace` 和相对路径指向该会话的项目目录；插件可以继续使用 `node:fs`、`node:fs/promises`，无需采用 Sugar 专用的保存 API。原始文件和返回给会话的路径属于同一个项目。

没有关联工作区的插件操作，看不到 `/workspace`，也不能创建这个入口。读操作返回 `ENOENT`，写操作返回 `EACCES`。在工具调用中发起的异步任务保留原工作区身份，读写时重新读取会话权限。切换前台会话不会把任务的输出转移到另一个项目。

支持常用同步、callback、Promise 文件方法、读写流和基础 FileHandle。跨工作区复用文件句柄会被拒绝；宿主与项目之间的 `copyFile` 采用分块复制，并保留排他创建语义。单次文件 RPC 上限为 32 MiB，较大文件应使用流。支持 `glob` / `globSync` / `fs.promises.glob` 和 `opendir` / `opendirSync` / `fs.promises.opendir`。尚未实现的工作区持续监听方法（如 `watch`、`watchFile`）仍明确返回 `ENOTSUP`。

## 文件匹配与目录遍历

`glob` 默认从当前会话的 `/workspace` 开始匹配，支持多个模式、`**`、花括号、`cwd`（含文件 URL）、`exclude`（模式数组或回调）、`withFileTypes` 和 `followSymlinks`。返回的目录项使用插件视图中的路径。匹配沿用 Node.js 24.22.2 的规则；权限、工作区归属和传输错误会明确返回，普通路径不存在则得到空匹配。匹配迭代器绑定创建时的工作区，不能转交给另一工作区继续读取。

`opendir` 返回可逐项读取的目录句柄，支持 `read` / `readSync`、`close` / `closeSync`、异步迭代、编码、读取缓冲大小和递归选项。异步迭代结束或提前退出会关闭句柄；目录句柄与普通文件句柄共用后端数量及空闲回收限制。递归打开每一层目录时重新检查工作区路径，不跟随目录符号链接跨出工作区。无工作区操作仍不能读取 `/workspace`。

Glob 引擎和匹配器的来源、许可证及本地改动见 [上游说明](plugin-glob-upstream.md)。

## 插件依赖

插件包和 `.dsh` 内的私有依赖会取得同一文件视图。未加载过的外部普通依赖也可以继承插件视图；已经由 DSH 宿主加载的非 SDK 共享依赖不能再安全复用。它们可能早已捕获宿主原始 `fs`，给模块 URL 添加 query 也不能隔离 CommonJS 缓存。Sugar 因此拒绝这类导入并返回 `ENOTSUP`，提示在插件包中安装私有依赖副本，避免悄悄把文件写进宿主目录。

官方 DSH/Cordis SDK 仍作为宿主服务共享，不在上述普通依赖拒绝规则之内。SDK 接口的权限与工作区语义由对应服务实现。兼容层不改写整个宿主的 Node 内置模块，也不把原生扩展直接系统调用当作受 Node 文件包装约束的操作。

验证入口：`node scripts/check-plugin-files.cjs` 和 `node scripts/check-plugin-routing.cjs`。后者同时覆盖 ESM/CJS 导入、并发工作区、异步任务身份，以及宿主已缓存依赖的拒绝行为。

## 子进程与自动化

插件工具中的 `spawn`、`exec` 和对应同步方法转发到原项目的工作进程，子脚本在实际项目文件系统中运行。原始命令参数和 stdin 分开传输，项目能力不放在命令行或子脚本环境里。只读会话暂不支持第三方插件创建子进程；不支持的 IPC/fork/worker_threads 等选项明确报错。

无工作区插件的子进程按需复用一个全局工作进程，默认目录 `/home/sugar`，可访问插件数据和临时文件。它使用同一 DSH 控制环境的程序和共享数据，但独立执行的目录提供方会阻止访问、创建 `/workspace`，子进程继承该视图。这个限制不修改主 DSH 的目录。服务有活动请求或后台子进程时保活，持续空闲 30 分钟后退出。

自动化任务会激活或创建已关联工作区的 Agent 会话，再投递提示词。工具执行沿用该会话的工作区身份，生成文件直接保存在该项目；它不属于无工作区的全局插件计时器。

## 验证

2026-11-19：本地真实 Node 模块、文件系统和回环 HTTP 回归通过；Android 15 真机的独立 Sucrune 测试环境使用 Node v24.22.2，验证了 Worker 同步 RPC、ESM/CJS 插件导入、并发项目、异步归属、只读限制和文件流。原 `@local/dsh-localdream` 源码保持不变，以本地模拟 SSE 响应执行原生图工具，PNG 编码及解码后像素核对通过，未调用真实生图接口或 root 搬运。

同机独立 execution 验证了无工作区目录视图：父进程与子进程均无法读取或创建 `/workspace`，仍可写 `/tmp`；同一环境的正常 execution 仍可读取原工作区标记。此验证没有重启或覆盖用户正在使用的 Sugar。
