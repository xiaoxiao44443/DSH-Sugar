本次将内置 DeepSeek Harness 升级至 **0.2.2-rc.5**，新增关于页，并改进页面拖动与运行时兼容性。

### 新增与改进

- **DSH rc.5**：包含新版搜索提供方自动选择、模型异常响应处理和 LiveShare 修复；已有搜索提供方配置保留。
- **关于页**：在「设置 → 通用 → 关于」查看应用图标、程序名与当前 APK 版本，通过手机浏览器打开 GitHub 源码仓库。版本号随安装包自动更新。
- **通用分组**：用「偏好设置」和「应用信息」小标题分隔界面语言、任务时常亮与关于入口。
- **页面拖动**：插件管理、插件市场、自动化任务及普通第三方主页面共用拖动预览，取消手势时保留原页面状态，改善往返和反向拖动体验。
- **运行时**：集成 Sucrune 已验证的 8 MiB 线程栈修复。
- **云端发布**：由 GitHub Actions 从固定源码和依赖构建，执行测试、签名与附件校验后发布。

### 下载安装

适用于 **Android 10 及以上的 ARM64 手机**。安装只需下载 **DSH-Sugar-0.2.1-arm64-v8a.apk**。

沿用原签名，同签名的旧版和测试版可直接覆盖升级，保留配置、会话和工作区数据。本版继续作为公开预览版发布。

本次改动已在 Android 15 真机验证启动、数据保留、插件/市场/任务页拖动、两种恢复模式，以及关于页的版本显示与浏览器跳转。

### 附件与来源

`SHA256SUMS.txt` 提供下载文件的 SHA-256。`third-party-notices.zip` 包含第三方许可证与组件来源，`debian-corresponding-source.zip` 包含内置 Debian 软件包的对应源码；这两个附件无需安装。
