本次新增虚拟屏接管与归还，改进桌宠气泡和消息通知，完善工作区文件浏览与插件文件兼容性。内置 DeepSeek Harness 仍为 **0.2.2-rc.5**。

### 虚拟屏与手机操作

- **接管与归还**：将虚拟屏中的同一个应用任务移到主屏，直接手动操作，再归还原虚拟屏。接管期间暂停该会话的手机操作，并在 Agent 步骤边界等待归还；归还后重新观察画面，避免继续使用旧截图和坐标。
- **复用主屏应用**：在虚拟屏打开应用时，可借入主屏已有的合适任务。关闭虚拟屏时归还借入任务、结束本屏新建任务；普通回合完成仍保留虚拟屏。完善应用被关闭、迁移失败和断连时的状态处理。
- **接管浮窗**：新增「回到应用」入口，在当前应用中自动显示为不可点击的「当前应用」。支持收起为横向胶囊，保留应用图标、名称和角色探头；采用紧凑布局、柔和阴影、随主屏背景调整的配色，以及受系统支持条件约束的背景模糊。
- **拖动与小窗识别**：改善虚拟屏预览拖动卡顿，触顶后停止移动，保持插图和窗口尺寸稳定。主屏观察补充当前窗口的位置与范围；窗口移动或缩放后要求重新观察，减少旧坐标误点。

### 桌宠与消息通知

- **气泡显示实际进展**：可显示命令说明、手机操作状态和助手回复。回复保留到首遍阅读结束，无新信息的轮询不再反复覆盖正文；长时间未更新时显示更新时间提示。
- **减少误导性报错**：命令非零退出码和工具异常不再自动触发「操作遇到了问题」气泡，保留在对话执行记录中，由 Agent 自己说明问题和处理进展。
- **通知显示正文**：完成通知显示回复内容，提问和审批通知显示对应说明；支持展开查看多行文字。新增默认开启的「桌宠免通知」，桌宠实际可见时暂停这些消息通知，锁屏或桌宠隐藏后恢复原通知规则。
- **完成提醒**：新建通知渠道使用高重要级别，具备横幅提醒条件；已有渠道保留用户的系统设置，最终展示由系统决定。

### 工作区与插件

- **文件浏览**：文件列表新增文件名自然排序，顺序为「大小、文件名、修改时间」，修改时间显示到分钟；移除缺少可靠数据的文件创建时间排序。接通文件夹菜单中的「在文件夹显示」，可打开对应目录。
- **插件文件接口**：补齐 `glob` / `globSync` / `fs.promises.glob` 和 `opendir` / `opendirSync` / `fs.promises.opendir`。插件可在所属工作区匹配文件、逐项或递归遍历目录，继续遵循工作区归属与权限；无需修改插件使用的常规 Node API。

工作区持续监听接口 `watch`、`watchFile` 仍未支持。详见[插件工作区文件说明](https://github.com/xiaoxiao44443/DSH-Sugar/blob/v0.2.3/docs/plugin-workspace-files.md)。

### 验证与安装

本地兼容性回归、195 项单元测试、APK 构建及 lint 错误检查已通过。新增文件接口覆盖原生 Node 行为对照、同步与异步调用、工作区隔离、目录句柄回收和异常处理；GitHub Actions 再次构建并校验签名与发布附件。

适用于 **Android 10 及以上的 ARM64 手机**。安装只需下载 **DSH-Sugar-0.2.3-arm64-v8a.apk**。

沿用原签名，同签名的旧版和测试版可直接覆盖升级，保留配置、会话和工作区数据。本版继续作为公开预览版发布。

`SHA256SUMS.txt` 提供下载校验和；`third-party-notices.zip` 和 `debian-corresponding-source.zip` 为第三方许可证、组件来源和对应源码附件，无需安装。
